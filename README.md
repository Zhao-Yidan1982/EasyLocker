# EasyLocker

包含两个小工具：用于生成随机二进制文件的 `RandomKey`，以及用于基于钥匙循环异或的 `Lock` 工具。

快速说明（适用于所有版本）：

- 构建：在支持 C++17 的编译器上分别编译两个源文件。

```bash
g++ -std=c++17 RandomKey.cpp -O2 -o randomkey
g++ -std=c++17 Lock.cpp -O2 -o lock
```

- 目的：
	- `RandomKey`：生成指定大小的随机二进制数据文件。
	- `Lock`：使用钥匙对任意文件按字节循环执行异或（XOR）操作以实现加密/解密。
